# Jounal Syantifik Kreyòl

Premye vèsyon frontend pou jounal syantifik an kreyòl ayisyen.

## Achitekti
- Frontend estatik HTML/CSS/JavaScript sou GitHub Pages
- Supabase Auth + PostgreSQL ak RLS
- Lis piblik la montre sèlman atik ki gen estati `published`

## Pibliye
Nan GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## Sekirite
Pa mete service_role oswa lòt kle sekrè nan frontend. Kle publishable Supabase la fèt pou kliyan piblik; tout aksè dwe respekte RLS.

## Pwochen etap
Ajoute espas otè, evalyatè, administratè ak telechajman PDF prive apre règleman otorizasyon yo fini.
